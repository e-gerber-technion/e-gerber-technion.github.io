2D Robot Arm Simulator & Kinematics Engine

An interactive web-based simulator demonstrating forward kinematics (FK) and basic motion programming of a planar robot arm. Features workspace visualization and real-time interactive controls. Built purely with HTML5 Canvas and JavaScript, using a Claude Sonnet 4.6 agent running in Antigravity.

Interactive Tool Web Simulation

UR-Style Forward Kinematics 3D Simulator

An interactive 3D robot simulator demonstrating forward kinematics (FK), DH parameter configuration, and multi-track trajectory playback (tool paths, base motions, and target visualizations). Features standard Denavit-Hartenberg (DH) parameter modification, custom CSV trajectory uploading, real-time 3D rendering with Three.js, and WebM video recording.
